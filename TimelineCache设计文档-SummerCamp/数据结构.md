# 数据结构
本文档仅作参考使用，主要的数据结构定义都在“cache数据详细设计与伪代码”和“数据精简模块详细设计与伪代码”两个文件中有最全面和具体的呈现。

本文档旨在详细定义“基于时间线的多模态资源引擎”项目中所使用的核心数据结构。这些定义将作为模块设计和编码实现的具体依据。所有数据结构均以c++伪代码+文字描述的方式进行叙述。

### 1. 核心数据包 (Core Data Packets)
数据包是引擎中数据流动的基本单元，分为外部传入和内部流转两种形态。

#### 1.1 RawResourcePacket
用途: 由外部 Resource Provider 构建，用于向引擎提交原始数据，提供了基础信息。

``` cpp
// C++ 风格伪代码
struct RawResourcePacket {
    // 资源的全限定名, 例如 "vehicle.signal.speed" 或 "camera.front_view"
    std::string resource_id;

    // 数据产生时的原始时间戳 (纳秒), 可选，若为0则引擎会自行生成
    uint64_t timestamp_ns;

    // 指向原始数据块的指针
    const void* data;

    // 原始数据块的大小（字节）
    size_t size;

    // [可选] 用于传递额外信息的元数据, e.g., 图像格式 "jpeg"
    std::map<std::string, std::string> metadata;
};
```
字段说明:

- resource_id: 数据的唯一标识符，采用点分格式以支持层级关系。
- timestamp_ns: 数据的原始时间戳，精度为纳秒。
- data: 指向数据内容的裸指针。
- size: data 指针所指向内存区域的大小。
- metadata: 键值对，用于携带与数据解析相关的额外信息。

#### 1.2 UnifiedDataPacket
用途: 引擎内部流转、存储和查询的标准数据单元。由 Data Ingestion & Adaption Layer 将 RawResourcePacket 转换而来。

``` c++
// C++ 风格伪代码
struct UnifiedDataPacket {
    // 引擎分配或校准后的唯一时间戳 (纳秒)
    uint64_t timestamp_ns;

    // 资源的全限定名
    std::string resource_id;

    // 资源的类型枚举，便于内部快速处理
    ResourceType type;

    // 指向数据载荷的智能指针，自动管理内存
    std::shared_ptr<void> payload;

    // 数据载荷的大小（字节）
    size_t payload_size;

    // 标记数据是否存储在共享内存中
    bool is_shared_memory;

    // 如果 is_shared_memory 为 true, 此处存储共享内存句柄
    SharedMemHandle shm_handle;
};
```
字段说明:

- timestamp_ns: 经过引擎确认的、用于在时间线上排序的权威时间戳。
- resource_id: 与 RawResourcePacket 中的定义一致。
- type: enum ResourceType，如 VEHICLE_SIGNAL, CAMERA, AUDIO 等，用于优化内部逻辑，避免字符串比较。
- payload: 使用 std::shared_ptr<void> 来灵活地指向任何类型的数据载荷（如 VehicleSignalData, ImageData 等），并自动管理其生命周期。
- is_shared_memory: 一个布尔标志，为 true 时表示 payload 实际应被忽略，数据需通过 shm_handle 从共享内存中获取。
- shm_handle: 当使用共享内存时，此句柄是访问数据的唯一凭证。
